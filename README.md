# IngreDiet

A mobile application designed to provide personalized nutrition programs and diet plans that promote a healthy lifestyle. The app generates recipes based on ingredients users have at home, catering to dietary preferences like gym-related diets, allergies, vegetarian needs, and more. It also offers solutions for common health issues (e.g., dizziness, headaches, hydration needs) through diet recommendations.

## Features

- **Ingredient-Based Recipe Generation**: Input ingredients you have at home, and the app will suggest recipes that fit your dietary goals.
- **Personalized Diet Plans**: Tailored diet plans based on individual needs, including gym-goers, vegetarians, users with food allergies, and people with specific vitamin/mineral deficiencies.
- **Health Recommendations**: Suggestions for common health problems (e.g., dizziness, headaches) to improve well-being.
- **Hydration Reminders**: Optional reminders to keep users hydrated throughout the day.
- **Nutrition Information**: Detailed nutrition breakdown for recipes, covering essential nutrients, calories, and more.

## Technologies

- **Frontend**: Kotlin (Android)
- **Backend**: Supabase for real-time database and user authentication
- **APIs**:
    - Nutrition API for diet and recipe suggestions
    - Supabase Auth for secure user login
- **Cloud Services**: Supabase for hosting, database management, and authentication

## Installation

1. **Clone the repository**:
   ```bash
   git clone https://gitlab.com/enchanted-coder/ingrediet.git
   ```
2. **Navigate to the project directory**:
   ```bash
   cd ingrediet
   ```
3. **Install dependencies**:
    - Install Kotlin dependencies for the Android project in your preferred IDE (e.g., Android Studio).
    - Configure Supabase by adding necessary keys in the project settings.

4. **Set up environment variables**:
    - Create a `.env` file in the root directory.
    - Add Supabase URL and API key, along with any other necessary environment variables.

5. **Run the application**:
    - Open the project in Android Studio, and run it on an emulator or connected device.

## Usage

1. **User Authentication**: Sign up or log in to create and save personalized diet plans.
2. **Input Ingredients**: Add ingredients you have at home to receive tailored recipe suggestions.
3. **Select Dietary Preferences**: Customize the diet plans based on allergies, vegetarian needs, or fitness goals.
4. **Track Health Needs**: Get dietary advice for symptoms like dizziness or headaches and enable hydration reminders.
5. **Save & Share**: Save favorite recipes and meal plans or share them with friends.
